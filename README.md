# Bookmark Manager

## Installation
Download the latest binary from [here](https://github.com/CamTroy/bookmark-manager/releases/) and run it from a terminal

### Developing

Requires [Bun](https://bun.sh/) 1.3.0 or later.

Clone this repository:

```bash
git clone https://github.com/CamTroy/bookmark-manager.git
```

To install dependencies:

```bash
bun install
```

To run:

```bash
bun dev
```

To typecheck:

```bash
bun run typecheck
```

This project is supposed to make keeping bookmarks simple and browser-agnostic, easy to make new bookmarks and open them in a default browser or copy the url and paste it where you want.
